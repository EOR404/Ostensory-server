自动更新设置

默认开启。后台启动后会定期检查，并在发现新版本时显示提示。检查只读取版本信息，不会自动改动文件。

默认关闭。开启后会在检查到新版本时自动下载、校验、备份并替换程序文件；仍需要重启服务才会运行新版本。后台不会自动杀进程，避免更新请求把自己中断。开启此项会同时开启自动检查。

数据安全说明
  • 更新只替换程序代码，不覆盖 data/ 目录。
  • 数据库、图片、主密钥、后台路径、账户和所有设置都会保留。
  • 安装前会生成 SQLite 一致性快照和旧程序备份，校验失败会停止。
  • 更新失败会尝试恢复旧程序；请保留备份目录，必要时按 README 手动回滚。
